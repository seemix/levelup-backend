# План реалізації CRM

> Специфікація: [spec.md](spec.md). Статус плану: **затверджено** (2026-11-13). Промти для етапів: [prompts.md](prompts.md).
> `[ ]` — не виконано, `[x]` — виконано. Уся робота — у гілці `crm` обох репозиторіїв (`levelup`, `levelup-front`), один або кілька комітів на етап; `master` не змінюється до запуску. Кожен етап завершується робочим станом.
> Модель: **opus** — модель даних, права, слоти, ціни, фінанси; **sonnet** — CRUD, UI, переклади, рутина.

## Контрольний список після кожного етапу
- `pnpm typecheck`, `pnpm lint`, `pnpm test:int` — зелені; у `levelup-front` — `npm run lint`, `npx tsc --noEmit`.
- Після змін схеми — `pnpm generate:types`; після нових компонентів — `pnpm generate:importmap`.
- Нові рядки UI є в ru/ro/en (тест `i18n-parity` зелений).
- Наявний сайт і адмінка працюють (лендинг відкривається, контент редагується).
- Чекбокси етапу в цьому файлі відмічено.
